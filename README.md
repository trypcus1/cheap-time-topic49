# Тема 49. Выбор дешёвого времени для работы прибора

> Практическая работа по дисциплине **«Основы алгоритмизации и программирования»**  
> Раздел: построение алгоритмов и блок-схем  
> Тема: подбор времени запуска бытовой нагрузки по почасовому тарифу

---

## 📌 О проекте

Программа подбирает **самый дешёвый непрерывный интервал** работы бытового прибора
в течение суток по почасовому тарифу на электроэнергию.

Пользователь задаёт:

- 24 цены за кВт·ч (по одной на каждый час суток);
- мощность прибора (кВт);
- длительность непрерывной работы (от 1 до 24 часов);
- разрешённое окно запуска и окончания.

Программа перебирает **все допустимые моменты старта** внутри окна,
считает стоимость каждого варианта и выбирает минимальную.
При равенстве стоимости выбирается **самое раннее начало**.

### Что делает алгоритм

1. Проверяет корректность входных данных (длительность, границы окна, тариф).
2. Определяет последний допустимый момент старта: `last_start = end_hour − duration`.
3. Перебирает все начала `start` от `start_hour` до `last_start`.
4. Для каждого начала строит список часов непрерывной работы.
5. Считает стоимость: `cost = мощность × Σ(цены часов)`.
6. Сохраняет вариант и в конце выбирает лучший по ключу `(cost, start)`.
7. Выводит **все допустимые варианты** с ценой и **рекомендуемый интервал**.

### Ключевое ограничение темы

> Два дешёвых часа, **разделённых дорогим**, нельзя «склеить» для непрерывной
> двухчасовой работы.

Алгоритм всегда берёт **непрерывный** интервал и не пропускает дорогие часы,
поэтому «склейка» невозможна по построению.

---

## 🧠 Модель данных

| Сущность | Назначение |
|---|---|
| `Device` | Прибор: название + постоянная мощность (кВт) |
| `Tariff` | 24 цены за кВт·ч |
| `LaunchWindow` | Разрешённое окно запуска `[start_hour, end_hour]` |
| `Variant` | Один допустимый вариант: начало, часы, стоимость |
| `ScheduleResult` | Все варианты + лучший интервал |

Ограничения модели: **один прибор, один день, постоянная мощность**,
без управления электроприборами.
